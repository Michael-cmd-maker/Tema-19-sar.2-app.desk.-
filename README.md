
# Calculator-CS

Acesta este un calculator simplu realizat
in limbajul C#.

## Functionalitati

- Adunare
- Scadere
- Inmultire
- Impartire
- Verificarea impartirii la zero

## Instructiuni de rulare

1. Deschideti proiectul in Visual Studio.
2. Deschideti fisierul Program.cs.
3. Apasati Ctrl + F5.
4. Introduceti doua numere.
5. Selectati operatia dorita.

## Tehnologii

- C#
- .NET
- Visual Studio 2022
